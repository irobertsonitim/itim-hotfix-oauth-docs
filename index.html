ITIM Portal Hotfix Drive Sync

Internal ITIM utility for authorised staff. It uploads and downloads JSON hotfix status files to a designated Google Drive folder so client environments can sync installed hotfix information with the ITIM Portal.

Google Drive access

  • List JSON files in one shared folder
  • Upload / update JSON files in that folder
  • Download and delete those JSON files after processing
