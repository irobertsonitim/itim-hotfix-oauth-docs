Privacy Policy — ITIM Portal Hotfix Drive Sync

Last updated: 2026-11-06

This app accesses Google user data only via the Google Drive API to synchronise hotfix JSON files between client systems and the ITIM Portal.

Data accessed

Files and metadata inside one designated Google Drive folder used for hotfix sync (name, id, JSON content).

How data is used

  • Exporter: creates/updates a JSON file of installed hotfixes.
  • Importer: downloads those files, posts data to the ITIM Portal API, then deletes them from Drive.

Storage

JSON may be stored temporarily on Exporter/Importer servers per local retention settings. Drive is only a transfer location.

Sharing

Google user data is not sold. It is not shared with third parties except as needed to operate the ITIM Portal for authorised staff/customers.

Limited use

Google user data is used only for this hotfix sync feature, not for advertising or unrelated AI/model training.
